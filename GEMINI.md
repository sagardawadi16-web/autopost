# Autopost Workspace Guidelines & Invariants

## Core Principles
1. **Mandatory Grasping**: Always grasp and confirm the user's intent, visual style, technical requirements, and target channel BEFORE writing code or pipelines. If requirements are ambiguous, clarify first.
2. **Mandatory Checkpoints**: Deconstruct tasks into verifiable milestones (`checkpoints.md`). Stop at each checkpoint to verify with actual tests or generated artifacts before proceeding to the next.
3. **Never Miss the Mark**: Validate all video/audio assets against target aesthetics (e.g., `@GHIBLISTYLESTUDIO` cozy 90s village nostalgia, ASMR audio, Ken Burns motion). Always run through a quality gatekeeper before publishing.
